# VELORA Estates

A premium real estate platform combining cinematic
frontend design with full-stack software engineering.

## Project Status

Phase 1 — Luxury homepage prototype.

## Current Features

- Responsive luxury homepage
- Cinematic property imagery
- Mobile navigation
- Scroll animations
- Featured concept residences
- Contact section

## Planned Features

- React frontend
- Java Spring Boot REST API
- PostgreSQL database
- Property search and filtering
- Property detail pages
- Admin dashboard
- Authentication and authorization
- Property CRUD operations
- Enquiry management
- Automated testing

## Technology Stack

Current:
- HTML5
- CSS3
- JavaScript

Planned:
- React
- Java / Spring Boot
- PostgreSQL
- Docker
- GitHub Actions
